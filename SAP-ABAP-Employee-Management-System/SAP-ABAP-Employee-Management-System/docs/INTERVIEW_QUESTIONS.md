# Interview questions for this project

1. **What is a transparent table?**  
   A transparent table has a one-to-one relationship with a physical database table.

2. **What is SE11 used for?**  
   SE11 is the ABAP Dictionary transaction used to create and maintain tables, views, data elements, domains, and other Dictionary objects.

3. **What is Open SQL?**  
   Open SQL is SAP's database-independent SQL interface used in ABAP programs to access database data.

4. **What is an internal table?**  
   An internal table is an in-memory ABAP data structure used to store and process multiple rows during program execution.

5. **What is a selection screen?**  
   It is the standard ABAP input screen used to accept parameters and selection criteria before report execution.

6. **What is ALV?**  
   ALV (ABAP List Viewer) provides a structured way to display tabular application data, with functions such as sorting, filtering, and layout handling depending on the ALV implementation.

7. **Why use `CL_SALV_TABLE`?**  
   It is an object-oriented SALV class that can create a read-only ALV table display with relatively little code.

8. **What is the Table Maintenance Generator?**  
   It generates a standard maintenance dialog for a table so authorized users can maintain entries, commonly through SM30.

9. **What is the purpose of a primary key?**  
   It uniquely identifies a row in a database table.

10. **How could you improve this project?**  
    Add authorization checks, validation, automated tests, application logging, and a modern UI or RAP/OData service.
